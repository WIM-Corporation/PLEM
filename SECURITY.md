# Security

Please do not report a security problem in a public issue. Report it privately on GitHub instead: in this
repository's **Security** tab, choose **Report a vulnerability**
(https://github.com/WIM-Corporation/PLEM/security/advisories/new). Include:

- the version (the tag you built);
- what an attacker can do, and the steps or code that show it;
- whether it needs local access, the EtherCAT network, or a ROS 2 network.

Supported: the latest tag. A fix ships in a new release, not as a patch to an older one.

We answer in the same advisory with what we plan to do. The fix's `CHANGELOG.md` entry and the published advisory
credit you if you want to be named.
